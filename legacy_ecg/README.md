# Archived ECG work

Đây là tài liệu, mã nguồn, notebook, metadata, bản ghi và hình minh họa của hướng nghiên cứu MIMIC-IV-ECG trước đây. Được chuyển nguyên trạng ngày 2026-09-21 để không lẫn với pipeline laboratory multi-label hiện tại.

Dữ liệu MIMIC-IV v3.1 HOSP vẫn ở `../data/hosp/` và không bị thay đổi. Các file ECG trong `legacy_ecg/data/` là dữ liệu cũ; không dùng làm input cho đề tài hiện tại.

Các báo cáo HOSP còn áp dụng nằm ở `../docs/`.
