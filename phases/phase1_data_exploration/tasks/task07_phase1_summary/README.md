## File chính

- `report/REPORT_task07.docx`: báo cáo Word hoàn chỉnh.
- `report/REPORT_task07.md`: bản Markdown.
- `outputs/decision_register_task07.csv`: nhật ký quyết định và câu hỏi còn mở.
- `outputs/phase2_proposed_plan_task07.csv`: kế hoạch Phase 2 đề xuất để thảo luận.
- `scripts/build_report_task07.py`: script tái tạo toàn bộ đầu ra.
